# mattpocock-skills

Vendored copy of the promoted skills from https://github.com/mattpocock/skills (MIT, Copyright 2026 Matt Pocock).

This is not a fork. `Shammn96/skills` was already the Anthropic skills repo, so GitHub could not fork `mattpocock/skills` onto that name.

## Install on the machine that runs the agent

Claude Code, inside a session:

```
/plugin install mattpocock-skills
```

Other agents:

```bash
npx skills@latest add mattpocock/skills
```

Then run `/setup-matt-pocock-skills` once per repo.

Install from upstream. This copy is for reading and editing.
